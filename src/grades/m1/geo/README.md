## วิธีใช้เครื่องมือบนกระดาน (ตามที่เด็กทำ)

- **วงเวียน** (ตอนเลือกวงเวียนจะเห็นวงเส้นประสีชมพูรอบเข็ม)
  ลากเข็ม (หรือตัววงเวียน) ไปวางที่จุด — ดูดติดจุด/จุดตัดในระยะ ~30 px
  ลากขาดินสอ (จุดชมพู) = **กางรัศมีอย่างเดียว ไม่เขียน** · ลากไปวางบนจุด = รัศมีเท่าระยะถึงจุดนั้นพอดี (ลอกความยาว) · ลากวนโดยระยะเท่าเดิม = หมุนเฉย ๆ รัศมีไม่เปลี่ยน
  **เขียนส่วนโค้ง** = แตะบนวงเส้นประตรงที่จะเริ่มแล้วลากไปตามวง (รัศมีล็อก) หรือหมุนปุ่ม ⟳
  ขณะเขียน ดินสอแตะกระดาษเฉพาะเมื่อนิ้วอยู่ใกล้แนววง · ลากไป-กลับได้ ส่วนโค้งครอบคลุมทุกที่ที่ลากผ่าน · ปลายส่วนโค้งเผื่อ ~3° ตอนหาจุดตัด
- **สันตรง**: จับแถบตัวเลขย้าย · ⟳ หมุน (ดูดเข้าแนวจุด) · ลากตามขอบบน = ลากเส้น
  เริ่มใกล้จุด = ดูดติดจุด · ลากไปถึงจุด = ดูดติด · ลาก**เลย**จุด/จุดตัด/✕ ที่เกือบอยู่บนแนวไม้บรรทัด (≤10°) = เส้นหมุนให้ผ่านจุดนั้นพอดี
- **ครึ่งวงกลม**: จับด้านในย้าย (ดูดติดจุดยอด ~32 px) · ⟳ หมุน (ดูดทับแขนมุม) · แตะ/ลากตามขอบสเกล = เห็น ✕ กับตัวเลของศาก่อน ปล่อย = ทำเครื่องหมาย
- **จุด**: แตะ (ดูดติดจุดตัด)
