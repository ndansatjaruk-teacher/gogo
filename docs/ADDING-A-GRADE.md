## 1. ข้อมูลที่ต้องขอจากผู้ใช้ก่อนเริ่ม

| ข้อมูล | จำเป็น | หมายเหตุ |
|---|---|---|
| ชั้น | ต้องมี | ชั้นที่มีอยู่แล้ว (ทำใหม่ทั้งชั้น) หรือชั้นใหม่นอก ป.1–ป.6 |
| รายชื่อบท แยกภาคเรียน 1 / 2 | ต้องมี | `chapter` ต้องขึ้นต้น "บทที่ N …" ตรงกับหนังสือเรียน (เลขบทขึ้นบนแท็บเมือง) |
| รายชื่อด่านต่อบท + จุดประสงค์ 1 ประโยคต่อด่าน | ต้องมี | ถ้าได้รายการคลิป: 1 คลิป = 1 ด่าน ใช้ชื่อคลิปเป็นชื่อด่าน (ห้ามใส่ลิงก์คลิป) |
| ขอบเขตตัวเลข/ข้อตกลงหน่วย | ต้องมี | เช่น ป.1 ≤ 100 · ป.2 ≤ 1,000 · ป.3 ≤ 100,000 · 1 เดือน = 30 วัน — เพิ่มกฎใน `tests/range.py` |
| จำนวนข้อเกมขั้นต่ำ | ไม่บังคับ | ค่าเริ่มต้น 8 (`GAME_MIN`) · ปรับรายชั้นที่ `gameMin(L)` ใน `app/app.js` |
| แบบโจทย์/สื่อที่ครูอยากให้มี | แนะนำ | แต่งใหม่เอง ห้ามคัดลอกข้อสอบของผู้อื่น |
| ชื่อโลก ธีม บอส | ไม่บังคับ | เสนอให้ผู้ใช้เลือกก่อนลงมือ |

## 2. สิ่งที่ต้องสร้าง (ตามลำดับการเล่น)

1. **ด่าน** (ต่อบท): `{ id, place, title, short, tone, goal, teach: [...], game: () => [...] }`
   - `id` ไม่ซ้ำ ไม่เปลี่ยน — จองช่วง id ใหม่ แล้วบันทึกในหัวข้อ "ช่วง id ด่าน" ของ ARCHITECTURE.md
   - `place` = คำตามธีมโลก + เนื้อหา (ป.1 ไม่มี `place`) · `short` ≤ ~14 ตัวอักษร
   - หน้าบทเรียน: รู้จักก่อน (`lrnBoard`) → ปรับเล่นเอง (sim) → ตัวอย่างทีละขั้น → ลองทำเอง (ข้อทดลองเล่น 2 ข้อ ระบบเติมให้จากเกม)
   - เกม: ≥ 2–3 ข้อต่อหัวข้อที่สอน สุ่มตัวเลขได้ · ทุกข้อต้องใช้ความรู้/วิธีคิดตามจุดประสงค์ของด่าน (ด่านสอนวิธีคิด ห้ามมีข้อ "หาผลบวก" เฉย ๆ)
2. **ด่านพิเศษ** (ไม่บังคับ): `bonus: true`
3. **บอสท้ายบท**: `boss: true`, `exam` ~20 ข้อ, `bossName`, `bossPal`, `emblem`, `bossKind`, `winLine`, `loseLine` — เกณฑ์ 80% ตั้งให้อัตโนมัติ (`BOSS_PASS`)
4. **สอบปลายภาค 1 และ 2**: `termLesson(...)` 40 ข้อ จับเวลา + `*_STORY` (บอสทุกบทกลับมารวมร่าง) — ดู `grades/p1/p1e.js`
5. **บอสใหญ่ของชั้น**: เมือง `final: true` (และ `secret: true`) เปิดเมื่อชนะบอสท้ายบทครบ
6. **ทะเบียน**: ไฟล์ `src/grades/p<ชั้น>/p<ชั้น><ตัวอักษร>.js` (prefix ชื่อไม่ชนไฟล์อื่น) → `src/order.txt` (ก่อน `app/lessons.js`) → เมืองใน `CITIES` (`grade`, `term`, `chapter`, `theme`) ตามลำดับการเล่น
7. **ชั้นใหม่นอก ป.1–ป.6 เท่านั้น**: เพิ่มใน `GRADES` (`id`, `name`, `world`, `cls`) · ธีมโลกใหม่ (`WORLD_OF` ใน `app/app.js`, ฉาก/สีใน `style.css`, ฉากเคลื่อนไหวใน `engine/life.js`) · บอสรวมร่าง (`megaMinis`) · ข้อสอบรวมของชั้น

## 3. ระบบกลางที่ได้ฟรี (ไม่ต้องเขียนใหม่)

- ปุ่ม "ถัดไป" ล็อกจนทำครบ (`teachGate`): ปุ่มขั้นต่อไปกดครบ · ของที่ให้แตะดูแตะครบทุกอัน (`EXP_SEL` / `EXP_SEL2`) · รูปที่นับต้องนับครบ — ของแตะชนิดใหม่ที่ต้องแตะครบ ให้เพิ่ม selector ใน `EXP_SEL2`
- ปุ่ม **?** ในแถบไก่: หน้าเรียนบอก "ขั้นนี้ต้องทำอะไร" (ใส่ `help:` ในขั้นได้) · เกมบอกวิธีตอบตามชนิดข้อ + คำใบ้ล่าสุด (`QGUIDE` — ชนิดข้อใหม่ที่ต้องอธิบายวิธีตอบ ให้เพิ่มรายการ)
- `gameSet`: ไม่ซ้ำ (รวมตัวอย่างในบทเรียนและข้อทดลองเล่น) · ง่าย → ยาก · กระจายชนิดข้อเท่า ๆ กันและสลับกัน · ขั้นต่ำ `gameMin`
- ตอบผิด: ครั้งที่ 1 ลองใหม่ · 2 คำใบ้ (`hintLeaks` กันเฉลย) · 3 เฉลย
- แผนภูมิรูปภาพแตะนับได้ (`pictoChart`) · แป้นตัวเลข/เขียนด้วยนิ้ว (`answerBox`) · กระดานตั้งบวกลบคูณ (`colw`)
- ชนิดคำถามที่มีอยู่: [QUESTION-TYPES.md](QUESTION-TYPES.md) — ใช้ซ้ำก่อนสร้างใหม่
