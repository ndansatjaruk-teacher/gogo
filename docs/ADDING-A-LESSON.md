# วิธีเพิ่มด่าน / บทใหม่

ตัวอย่างทั้งหมดในหน้านี้มาจากโค้ดจริงใน [`src/grades/p5/p5q.js`](../src/grades/p5/p5q.js) (ป.5 บทที่ 7 รูปสี่เหลี่ยม) — เปิดไฟล์นั้นดูคู่กันได้

## 1. ด่านหนึ่งด่านคืออะไร

ด่าน = object หนึ่งตัว:

```js
{ id, place, title, short, tone, goal,
  teach: [ T(ข้อความ, คำพูด, el => el.append(สื่อ)), … ],   // หน้าบทเรียน ทีละหน้า
  game:  () => [ คำถาม, คำถาม, … ] }                        // เกมผ่านด่าน (สร้างใหม่ทุกครั้งที่เล่น)
```

แต่ละชั้นมีตัวช่วยย่อ เช่น ป.5 บทที่ 7:

```js
const L5Q = (no, place, title, short, goal, teach, game) => ({ id: 630 + no, place, title, short, tone: TONES5[(no + 1) % 6], goal, teach, game });
```

- **`id` ห้ามซ้ำและห้ามเปลี่ยน** — ดาวของเด็กถูกเก็บตาม id ดูช่วง id ของแต่ละชั้น/บทในหัวข้อ "ช่วง id ด่าน" ของ [ARCHITECTURE.md](ARCHITECTURE.md)
- `place` = ชื่อสถานที่บนแผนที่ (ตามธีมของชั้น เช่น ป.5 = ถ้ำ…) · `title` = ชื่อด่านตามหลักสูตร · `short` = ชื่อสั้นบนการ์ด · `goal` = จุดประสงค์การเรียนรู้

## 2. หน้าบทเรียน (`teach`)

```js
T('<b>ลองสร้างจริง</b>: คางหมู ABCD ให้ AB = 7 ซม. …',      // ข้อความในกล่องคำพูด (HTML ได้)
  'ลองสร้างคางหมูจริง ติดตรงไหนกดคำใบ้',                      // ประโยคที่ระบบอ่านออกเสียง
  el => el.append(cnsFree(cnsTrap(7, 65, 4, 3.5))))          // สื่อโต้ตอบที่วางบนหน้า
```

- หน้าที่มีสื่อโต้ตอบจะ **ล็อกปุ่ม "ถัดไป"** จนกว่าเด็กทำตัวอย่างเสร็จ (`teachGate` ใน `app/app.js`):
  ปุ่มลำดับขั้น (`.btn.info` / `.accent` / `.primary`) ต้องกดครบ หรือสื่อเรียก `teachDone(el)` เอง
- ลำดับหน้าที่ใช้กันทั้งเกม: **ปรับเล่นเอง (sim)** → **ตัวอย่างทีละขั้น** (กดทีละขั้น เห็นภาพทุกขั้น) → **ลองทำเอง**
- หน้า "รู้จัก" หลายหน้าเรื่องเดียวกันให้ใช้ `lrnBoard` (`engine/learnkit.js`) — แผนภาพสะสมจากหน้าแรก (ยกเว้นเรื่องเวลา)

## 3. เกม (`game`)

```js
() => [
  Q.dPick({ q: 'การสร้างรูปสี่เหลี่ยมคางหมู ต้องลากเส้นใดให้ขนานกับฐาน', opts: ['ด้านบน (ด้านตรงข้ามฐาน)', 'เส้นทแยงมุม', 'ด้านเอียง'], right: 'ด้านบน (ด้านตรงข้ามฐาน)' }),
  Q.t6Num({ q: 'รูปสี่เหลี่ยมคางหมู ABCD มี AB ขนานกับ DC และมุม A = 65° มุม D มีขนาดกี่องศา', a: '115', unit: 'องศา', hint: 'มุม A + มุม D = 180°' }),
  cnsGen.trap(), cnsGen.trap(),
]
```

- หาชนิดคำถามที่มีอยู่แล้วใน [QUESTION-TYPES.md](QUESTION-TYPES.md) ก่อนเขียนชนิดใหม่
- ฟังก์ชัน `game` ถูกเรียกหลายรอบ แล้ว `gameSet()` (`app/app.js`) คัดข้อ: ไม่ซ้ำ · กระจายชนิดคำถาม · เรียงง่าย → ยาก (`__diff`) · อย่างน้อย 8 ข้อ
  ให้ใส่ข้อมากพอ (~2–3 ข้อต่อหัวข้อที่สอน) และสุ่มตัวเลขในข้อได้ยิ่งดี
- ข้อที่ใช้เวลานานจำกัดจำนวนต่อเกมได้ด้วย `__base` + `__baseCap` (+ `__baseHard: true` = ห้ามเกินแม้ข้อไม่พอ) — ดู `Q.cnsQ`

### เขียนชนิดคำถามใหม่

```js
Object.assign(Q, {
  myType({ q, a, hint }) {
    return { prompt: q, say: q, __sig: 'myType ' + q,          // __sig = ลายเซ็นกันข้อซ้ำ
      mount(bd, ctx) {                                         // วาดคำถามลงใน bd
        … ctx.check(ถูกไหม, 'คำใบ้/เหตุผลที่ผิด') …              // เรียกเมื่อเด็กตอบ
      } };
  } });
```

- `ctx.check(false, เหตุผล)` → ระบบจัดการกฎ "ผิดครั้งที่ 1 ลองใหม่ · ครั้งที่ 2 คำใบ้ · ครั้งที่ 3 เฉลย" ให้เอง
  (ครั้งที่ 3 จะเรียก `.reveal()` ของ element ที่มี class `ans` / `opts` / `rvl` — ทำให้ `reveal()` แสดงคำตอบที่ถูกบนจอ)
- คำใบ้ห้ามบอกคำตอบตรง ๆ (`hintLeaks` ตรวจให้)
- คำตอบตัวเลขใช้แป้นตัวเลขที่มีอยู่ (`answerBox` / `Q.t6Num` / `Q.hNum` …)

## 4. บทใหม่ทั้งบท

1. สร้างไฟล์ `src/grades/p<ชั้น>/p<ชั้น><ตัวอักษร>.js` เช่น `p5z.js` ตั้ง prefix ชื่อฟังก์ชันของไฟล์ (เช่น `z5…`) กันชื่อชนกับไฟล์อื่น
2. เพิ่มบรรทัดใน [`src/order.txt`](../src/order.txt) **หลัง** ไฟล์ที่ใช้ของ (ปกติวางต่อจากไฟล์อื่นของชั้นเดียวกัน) และ **ก่อน** `app/lessons.js`
3. ประกาศ `const LESSONS_P5C9 = [ … ]` และด่านบอส (`boss: true` — ดูท้าย `p5q.js` · เกณฑ์ชนะ 80% ตั้งให้อัตโนมัติ)
4. ลงทะเบียนเมืองใน `CITIES` ของ [`src/app/lessons.js`](../src/app/lessons.js) (ลำดับใน `CITIES` = ลำดับการเล่น) พร้อม `theme` ตามโลกของชั้นนั้น
5. `python3 tools/build.py --check` → `python3 tests/smoke.py --grade 5` → เปิด `dist/index.html` เล่นจริงบนจอขนาดไอแพด
6. เพิ่มหัวข้อสั้น ๆ ใน [ARCHITECTURE.md](ARCHITECTURE.md) และรัน `python3 tools/catalog.py` ถ้าเพิ่มชนิดคำถาม
